Privacy policy

Read how data stays local

Effective 6 September 2026

OTel Token Meter works without sending trace data to us or another company.

The website

This static site uses no cookies, analytics, ads, fingerprinting, remote fonts, or remote scripts.

Our host may process IP address, time, path, and browser details in short-lived security logs.

The CLI

The CLI has no product telemetry and makes no outbound request. It receives OTLP/HTTP on the address you choose.

The default address is loopback. The ledger stores grouped token, cache, duration, error, and cost totals.

It does not store prompts, responses, trace IDs, span events, or individual trace records.

Your control

Your aggregate data is the JSON file passed with --data. You can inspect, move, or delete it.

Configure your exporter to omit prompt and response bodies for added protection.

Contact

Open a privacy or security issue in the public repository. Do not include private trace data.
