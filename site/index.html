Three steps

Collect, group, and export totals

Use an existing OTLP exporter. No model proxy or extra tracing SDK is required.

  1. 01

    Receive OTLP traces

    The local endpoint accepts OTLP/HTTP JSON or protobuf. It supports identity and gzip encoding.

  2. 02

    Store aggregate totals

    The collector maps common GenAI attributes. Missing project, model, or tool names stay visible as unknown.

  3. 03

    Report and export

    Read a terminal table or stable JSON. Export the same grouped totals as CSV.

Aggregate-only storage

Keep trace content out of the ledger

Prompt text, response text, trace IDs, events, and individual spans are not stored.

The ledger contains grouped counters, durations, errors, cost totals, and its last update time.

Install the local collector

Install from source, then send OTLP traces to the loopback address.

cargo install --git https://github.com/B-Divyesh/sf-otel-token-meter
otel-token-meter serve --data ./token-meter.json
